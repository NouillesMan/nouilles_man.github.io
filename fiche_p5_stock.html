Contexte & Objectifs

Le suivi du matériel d'une base militaire (assets, missions, bases) était dispersé et difficile à tracer. L'objectif est de centraliser ce suivi dans une application web sécurisée, conforme aux recommandations de l'ANSSI, avec gestion des assets, des missions et des bases, contrôle d'accès par rôles et authentification renforcée.

Informations générales

Front-endReact 19 + TypeScript (Vite)
Back-endFlask 3 (Python) + SQLAlchemy
Base de donnéesPostgreSQL (via Docker)
AuthentificationJWT RS256 (cookie httponly) + Argon2 + 2FA TOTP
Monorepopnpm + Turbo — CI GitHub Actions
Dépôt GitHubBTS-ESNA-2024-2026/P5-stock (privé)

Technologies utilisées

React 19 TypeScript Vite Flask 3 Python SQLAlchemy PostgreSQL Docker JWT RS256 Argon2 2FA TOTP REST API pnpm / Turbo GitHub Actions

Fonctionnalités principales

  • Tableau de bord avec statistiques
  • Gestion des assets, missions et bases (CRUD complet)
  • Contrôle d'accès par rôles — RBAC à 5 rôles
  • Authentification JWT RS256 en cookie httponly/Secure/SameSite
  • Mots de passe hachés avec Argon2
  • Double authentification (2FA TOTP)
  • API REST consommée par le front React
  • Conformité aux recommandations ANSSI

Difficultés rencontrées

  • Mise en place de l'authentification JWT RS256 + 2FA TOTP
  • Coordination en équipe sur un monorepo partagé (conflits Git)
  • Structuration de l'API REST Flask et du front React
  • Synchronisation Docker + PostgreSQL au démarrage

Solutions apportées

  • Clés RSA pour signer/vérifier les JWT (RS256), TOTP pour la 2FA
  • Branches Git, pull requests et CI GitHub Actions systématiques
  • Monorepo pnpm + Turbo séparant clairement front et back
  • Healthcheck Docker Compose pour attendre PostgreSQL

Bilan & acquis

Ce projet m'a permis de travailler sur une application full-stack moderne (React 19 + TypeScript / Flask 3 + PostgreSQL) organisée en monorepo pnpm + Turbo, et de mettre en place une authentification robuste conforme ANSSI (JWT RS256 en cookie httponly, Argon2, 2FA TOTP, RBAC à 5 rôles). Le travail en équipe sur GitHub avec intégration continue m'a également permis d'acquérir de solides pratiques de gestion de version et de collaboration en mode projet.
